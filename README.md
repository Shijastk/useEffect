# Anti Bakery: React + Vite, FINAL (Week 4, Day 3 answer key)

What the starter becomes by the end of the class:

- `App.jsx`: products loaded with `fetch` inside `useEffect`, with loading, error and empty states,
  a search box (dependency array `[search]`), an `AbortController` cleanup, and a `document.title` effect.
- `OrderForm.jsx`: `POST`s the order to the API from the submit handler (no effect needed).

Run it the same way as the starter: `npm install`, then `npm run api` and `npm run dev` in two terminals.
